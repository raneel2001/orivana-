# Orivana Solutions Website

This is a free static website you can host with GitHub Pages.

## Files
- index.html
- style.css
- script.js

## Publish for free on GitHub Pages

1. Create a free account at https://github.com
2. Create a new repository, for example: `orivana-solutions`
3. Upload `index.html`, `style.css`, and `script.js`
4. Open the repository settings
5. Go to **Pages**
6. Under **Build and deployment**, choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
7. Save
8. GitHub will give you a free URL such as:
   `https://yourusername.github.io/orivana-solutions/`

## Connect your own domain later

If you buy a domain such as `orivanasolutions.com`, you can connect it to GitHub Pages from:
Settings → Pages → Custom domain.

You will also need to add the DNS records requested by GitHub at your domain provider.

## Important edit

In `index.html`, replace:

hello@orivanasolutions.com

with the email address you actually want to use.

## Contact form note

The current contact button opens the visitor's email app using `mailto:`.

For a true website form that sends submissions without opening an email app, you can later use a free service such as Formspree or Web3Forms.
